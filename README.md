# Alfred Jira Lookup

Alfred Workflow to quickly lookup and open Jira issues.

# Prerequisites
- Jira account access
- Jira API credentials configured (if needed)

# Installation
[Download](https://github.com/sherifabdlnaby/alfred-jire-lookup/releases/latest) the latest `alfred-jire-lookup-*.alfredworkflow` file from [Releases](https://github.com/sherifabdlnaby/alfred-jire-lookup/releases/latest).

# Usage
1. Open Alfred and type `jira` to search for Jira issues.
